 KEY METRICS & THRESHOLDS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PATTERN APPROVAL CRITERIA (Auto-Validation):
├─ Minimum matches: 3 occurrences in historical data
├─ Minimum win rate: 70% (7 out of 10 correct predictions)
├─ Minimum avg move: 50 points (NIFTY specific)
├─ Minimum consistency: 30% of trading days (pattern repeats)
└─ Status: APPROVED if ALL criteria met

ENTRY SIGNAL GENERATION:
├─ Confidence threshold: > 0.70 (must exceed for signal)
├─ Confidence formula: (backtest_score × 0.60) + (weight × 0.25) + (indicator_align × 0.15)
├─ Pattern weight: derived from backtest win rate
└─ Execution: Automatic when confidence > 0.70

PATTERN LIFECYCLE:
├─ Discovery: Each night (11:00 PM)
├─ Validation: Against 13 trading days of data
├─ Approval: Auto-approved if metrics pass
├─ Storage: In ChromaDB with 7-day expiry
├─ Retirement: Auto-retire if win rate drops < 60%
└─ Refresh: New patterns discovered every night
